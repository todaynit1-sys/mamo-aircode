# 에어코드 · AIRCODE

[앱 열기](https://mamo-aircode.vercel.app/)

대기오염물질 배출허용기준·배출시설 검색 앱입니다.

- 모바일 한 열 목록과 읽기 쉬운 기준·조건 표시
- 대기오염물질 64개 / 특정대기유해물질 35개 목록
- 조건별 배출허용기준 515개와 시설 분류 37개
- 법령 PDF 4종 및 원문 이미지
- 물질별 검색, 보관함, 홈 화면 설치, 카카오톡 링크 미리보기

제작: 신현준연구사(hjuni@korea.kr)

이 저장소는 배포된 정적 웹사이트 파일입니다. Vercel은 main 브랜치의 루트에서 배포합니다.
첨부 법령을 기반으로 하며 최신 개정 여부와 개별 시설의 적용 조건은 현행 법령에서 확인하세요.


## 관련 앱

상단의 **AI 환경비서로 이동**으로 5개 환경법령 관리요령·자가점검·위반사례 앱을 열 수 있습니다.
[AI 환경비서](https://ai-ecoassist.vercel.app/)에서도 대기비서로 돌아오는 링크를 제공합니다.

## Vercel 배포 빌드

npm ci 후 npm run build를 실행하면 dist에 공개 실행 파일만 생성합니다. Vercel은 vercel.json에 지정된 이 폴더만 게시합니다.

- JavaScript는 실행 순서를 유지해 묶고 압축하며, 내용 해시가 있는 파일명으로 제공합니다.
- CSS·HTML·JSON을 압축하고 클라이언트 소스맵을 만들지 않습니다.
- README, 제작 프롬프트, 테스트, 빌드 도구, 개발 원본은 dist에서 제외합니다.
- 필요한 법령 자료·아이콘·공유 이미지와 기존 서비스워커의 오프라인 동작은 유지합니다.
- 개발 원본은 저장소에 보관합니다. 공개 저장소의 원본 열람은 별개이며 브라우저 실행 코드의 복사를 완전히 막지는 않습니다.
